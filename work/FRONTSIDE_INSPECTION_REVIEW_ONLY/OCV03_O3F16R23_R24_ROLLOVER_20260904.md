## Current diagnosis

The current green line is the normal bevel trace. It is removed inside
candidate-notch columns, so it cannot provide a full candidate contour. The
current red line is the unsmoothed pre-composition deep frontier and can jump
between parallel brightness bands. The candidate-specific native orange
contour is evaluated only after one unique BF/DF notch pair has already been
selected. Thus the contour evidence that could separate a smooth notch from a
jagged chipout or die edge arrives too late.

The solution is not stronger smoothing or a fitted ideal notch. A fit-first
method can pull unrelated die/chipout pixels onto a manufactured arch—the
exact defect the operator identified. The correct order is:

1. discover every full-360 indentation candidate without labels or a fixed
   notch window;
2. independently trace the actual shoulder-to-shoulder brightness-supported
   boundary for every candidate in each channel;
3. retain a raw/native transition witness for every accepted coordinate;
4. measure the resulting real contour;
5. only then decide whether its shape is compatible with a manufactured
   notch, an irregular non-notch deep-edge response, or an unresolved hold;
6. pair BF/DF evidence only after the channel-local contours and metrics exist.
